Bioinformatics Tools and Software

Assay-oriented software links for genome architecture, chromatin profiling, transcriptomics, proteomics, and image analysis.

These tools are grouped by the analysis problem a researcher is likely trying to solve. This is a curated orientation page, not an endorsement that every tool fits every dataset.
